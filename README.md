Repositório destinado aos estudos da disciplina de **Programação Imperativa e Funcional** do curso Tecnológico em Análise e Desenvolvimento de Sistemas (ADS) da **CESAR School** (Turma ADS20262_2A - Semestre 2026.2).

## 👨‍🏫 Docente
**Prof. Danilo Farias Soares da Silva**


* **Linguagem C (Imperativa):** comandos de entrada e saída; estruturas de decisão e repetição; matrizes, strings e tipos de dados estruturados; subprogramas, arquivos, conjuntos, ponteiros; alocação dinâmica de memória; introdução à programação modular.
* **Linguagem Haskell (Funcional):** listas, tuplas, tipos, classes, polimorfismo, funções de alta ordem, recursão.

## 🎯 Objetivos
* Dominar os conceitos básicos de programação imperativa e o gerenciamento de memória (ponteiros e alocação dinâmica) usando C.
* Compreender os princípios fundamentais da programação funcional, desenvolvendo a capacidade de resolver problemas de forma declarativa em Haskell.
* Entender as características, vantagens e desvantagens de cada paradigma na resolução de problemas computacionais.


## ⚙️ Ferramentas Utilizadas
- **C:** Compilador GCC, IDE recomendada (VS Code, CLion, etc.)
- **Haskell:** GHC (Glasgow Haskell Compiler) e GHCi (REPL)
- **Ambiente:** AWS Academy
